# CRM Call Tracking Template

## Purpose

This template helps sales teams record, monitor, and report B2B calling activity in an organized way.

## Recommended Fields

| Field | Description |
|---|---|
| Call Date | Date of the call |
| Call Time | Time of the call |
| Company Name | Prospect’s company |
| Contact Name | Person contacted |
| Job Title | Prospect’s role |
| Phone Number | Business contact number |
| Industry | Prospect’s industry |
| Location | Country, city, or region |
| Lead Source | Where the prospect was found |
| Call Outcome | Result of the call |
| Qualification Status | Qualified, unqualified, or pending |
| Interest Level | Low, medium, or high |
| Main Requirement | Prospect’s stated need |
| Objection | Main concern raised |
| Follow-Up Date | Planned follow-up date |
| Next Action | Required next step |
| Appointment Date | Meeting date, if booked |
| Notes | Additional relevant information |

## Call Outcome Options

- No answer
- Busy
- Wrong number
- Not interested
- Call back requested
- Interested
- Qualified lead
- Appointment booked
- Not a decision-maker
- Do not contact

## Daily Reporting Summary

At the end of each working day, report:

- Total calls attempted
- Calls answered
- Conversations completed
- Interested prospects
- Qualified leads
- Appointments booked
- Follow-ups scheduled
- Common objections
- Important client feedback
- Recommended next actions

## Reporting Principles

- Enter information immediately after each call.
- Keep records accurate and consistent.
- Avoid duplicate prospect records.
- Use clear and standardized outcome labels.
- Do not record unnecessary sensitive information.
- Protect client and prospect information.
- Report results honestly.
